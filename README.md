# PrintLab — 栅格印前工作台

PrintLab 是本地运行的图像印前与扫描校样工具。上传原稿、建立 CMYK 色版、生成网点、模拟叠印、测量扫描样张及查看图像质量，所有处理保存输入来源、参数、结果图和数据表。合成演示材料只用于体验，不代表真实印机观测。

## 启动

```bash
BUILDX_BUILDER=default docker compose up -d --build
```

页面为 http://127.0.0.1:18923 。Compose 使用独立项目 `solo23-printlab` 和持久化卷 `solo23-printlab_printlab-data`。普通停止用 `docker compose down`；该命令保留卷。不要加 `-v`，否则会删除自己的作业数据。

也可在 Python 3.11/3.12 环境安装 `requirements.txt` 后执行 `./start.sh`。默认数据目录为项目内 `data/`，可用 `PRINTLAB_DATA_DIR` 改为独立目录，用 `PORT` 改端口。推荐设置 `OPENBLAS_NUM_THREADS=1` 和 `OMP_NUM_THREADS=1`。

依赖锁分 Python 版本：3.11 使用 numpy 2.4.6/scipy 1.17.1，3.12 使用 numpy 2.5.4/scipy 1.18.1；Flask、OpenCV、Pillow 等由 requirements 固定。Dockerfile 的 `solo12-scanweave:1.0` 是本机已有第三方运行时镜像；构建会删除其中旧 `/app`，只复制当前 PrintLab 正常源码。若别的机器没有该本地镜像，可将基础镜像换为兼容的 Python 3.12 镜像并安装同一依赖文件。

## 体验完整流程

1. 点击“创建合成演示”，会产生原稿、带轻微位移和两个演示缺陷的校样、灰阶靶标、实色控制条及循环纹样，附带基础分色与叠印结果。
2. 选择原稿，在“颜色分解 / 基础 CMYK 分色”调整起黑点、灰成分替代和总墨量。处理后点选四通道 CMYK 结果，再进行下游操作。
3. 在“网屏制作”使用 AM 或 FM 网点；四版覆盖率会单独保存，叠印图仅是可视化。可对原连续调色版与网版做覆盖率比较，也可检测网点形状和频域峰。
4. 在“印机与油墨”应用手工曲线、网点扩大、指定油墨和纸白叠印，或按物理尺寸、印量、墨膜与损耗估算用墨。
5. 选合成扫描校样和原稿参考，使用全图平移或人工标点套准。用对应像素差异、密度网格、均匀性、清晰度和线段剖面检查结果。
6. 添加矩形区域后可测量、排除或参考采样。区域按当前图像的原始像素坐标保存；派生图像不会自动继承旧区域。点击预览可读取原始像素及邻域数值。
7. 灰阶靶标与控制条保存色块位置，可以直接测量。外部图像可输入 `name,x,y,width,height,channel,nominal` CSV 标定色块位置，再获取相对密度与颜色表。
8. 循环纹样可做接缝误差检查、循环偏移或重复排布；画布整理可做裁切、出血、旋转、四角平面校正。手工色版补偿仅做选定色版的扩缩。
9. 扫描整理提供纸白参考、背景平整、降噪、锐化、色阶及印刷尺寸重采样；每个操作保留原始输入。
10. 印张排布提供规则格、固定尺寸、方向比较、尺寸标尺与作业联系表。作业报告含来源链、完整参数、结果表和适用边界，可导出 HTML/JSON/CSV 或 ZIP。

## 数据、容量和近似

图像为 float32、0–1 RGB 或 CMYK 覆盖率数组；三通道和四通道有明确区别。上传 PNG/JPEG/TIFF 的多帧输入不支持，EXIF 朝向会应用，透明像素合成到白纸并保留原 alpha。ICC 元数据会记录，但不执行 ICC 颜色转换，CMYK 导入文件按 Pillow 的显示转换得到 RGB；需要独立版的用户可使用色版组装 API。

单图最多 4,194,304 像素、单边4096、上传24 MiB。页面最长边720像素预览；PNG/TIFF/NPY导出保留完整尺寸。单次仅运行一个图像处理，其他读取可并发，繁忙处理请求返回409。性能验证使用320×240正常流程、720×540演示原稿及最大1200×640左右的靶标；不承诺419万像素所有操作的交互速度。单作业图像多时，完整ZIP会占用额外内存，宜按当前实际工作量导出。

CMYK分色是基础灰成分替代，油墨模型是RGB透射率/遮盖近似，测量密度是相对纸白的分量负对数。AM为解析网点及有限子像素覆盖，FM为带确定种子的随机阈值，不宣称工业蓝噪声。频谱与MTF/笔画测量是可审阅的像素近似。平移、人工仿射和四角校正不处理局部纸张伸缩。规则拼版不做自动混排寻优。单版扩缩不自动识别相邻油墨和细字语义。

作业采用SQLite WAL和内容寻址图像文件；每次处理输出先落图像内容再在同一数据库事务登记操作与派生图。失败不替换原图。配置后续修改不改变已经落盘的像素和当时记录参数。数据目录和所有作者/验收材料均不属于源码。

## API与源码

`/api/catalog` 返回可用处理和参数；`/api/jobs` 管理作业，`/api/jobs/<id>/process` 执行处理，`/api/assets/<id>/preview`、`download`、`pixel` 返回图像与原始读数。独立色版上传使用 `/api/jobs/<id>/assemble-plates`，色版替换使用 `/api/assets/<id>/replace-plate`，均产生新图像。区域、配置、测量表比较、作业报告和ZIP都有对应API。

`printlab/` 是自有后台；`templates/` 和 `static/` 是页面；`scripts/count_backend.py` 为独立代码统计工具，不计入后台。没有外部服务账户、网络模型调用或后台发布行为。
